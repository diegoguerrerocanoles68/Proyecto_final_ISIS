# Entrega 1 – P1 Plataforma de autoaprendizaje digital (CLENA)
 
Levantamiento de requisitos y prototipo de la solución para la Sala de Internet del CLENA, elaborado por el equipo de Introducción a la Ingeniería de Sistemas y Computación, en alianza con el equipo de Desarrollo de Aplicaciones Web Backend (8.º semestre).
 
## Sobre el proyecto
 
Plataforma web de autoaprendizaje para la Sala de Internet del CLENA. Ofrece guías paso a paso y actividades de práctica para que adultos mayores y visitantes con poca experiencia digital aprendan solos, con énfasis en reconocer fraudes por internet, y permite pedir ayuda al monitor sin levantarse del puesto. Está pensada con accesibilidad: letra grande, alto contraste y botones grandes.
